# Txpuro GEO 增长方案

Last updated: 2026-05-05

## 1. 适用对象

本方案面向 `www.txpuro.com` 及其关联内容资产，目标产品为：

- `Txpuro / TxPuro E-Invoice System`
- 面向马来西亚市场的 `LHDN / MyInvois` 电子发票合规与开票系统
- 目标客户以 `本地中小企业`、`在马来西亚经营的华人企业`、`已有 ERP/财务系统的中大型企业` 为主

本方案按 GEO 视角设计，重点不是传统 SEO 排名，而是让 `ChatGPT`、`Perplexity`、`Gemini`、`Claude` 在回答以下问题时更容易提到、引用和推荐 Txpuro：

- 马来西亚电子发票系统怎么选
- MyInvois API 对接怎么做
- 中小企业如何上 LHDN e-Invoice
- 中国企业在马来西亚如何做电子发票合规

## 2. 当前判断

基于公开页面与索引结果，Txpuro 当前的最大问题不是“没有产品”，而是“产品实体分散”：

1. `Txpuro` 的核心介绍、FAQ、卖点，目前主要被 `qyeasy.com` 的服务页承载，而不是 `txpuro.com` 自身。
2. 搜索引擎和 AI 更容易把 `QYeasy / 永亨佳邦科技 / Txpuro` 识别成混合实体，导致产品名、品牌名、内容出处不稳定。
3. 当前强信号页面更像“服务介绍页”，还不够像“可被引用的产品知识库”。
4. 针对 `MyInvois`、`LHDN e-Invoice`、`SME implementation`、`self-billed invoice`、`credit note / debit note / void` 这些高意图问题，产品级解释页还不够系统。

## 3. 核心 GEO 目标

Txpuro 要在 AI 搜索里建立 3 层认知：

1. `实体认知`
   Txpuro 是一个独立可识别的马来西亚电子发票产品，不只是某个服务页里的名称。

2. `问题认知`
   当用户问 LHDN / MyInvois / e-Invoice 合规问题时，AI 会把 Txpuro 视为可操作的解决方案来源之一。

3. `场景认知`
   当用户问“中小企业怎么做”“华人企业怎么做”“已有 ERP 怎么接”“需要中文支持怎么办”时，Txpuro 要有明确答案。

## 4. 最重要的结构调整

这是优先级最高的动作。

### 4.1 统一主内容域

建议采用以下其中一种，不要长期双中心混跑：

1. 最优先：`txpuro.com` 作为产品主域
   - 产品页
   - 功能页
   - FAQ
   - 政策解读
   - 对比页
   - 文档页
   - 客户案例

2. 可接受：`qyeasy.com` 作为集团主站，`txpuro.com` 作为产品主域
   - `qyeasy.com` 保留品牌介绍和服务导航
   - 所有 Txpuro 深度内容 canonical 到 `txpuro.com`
   - `qyeasy.com` 的 Txpuro 页面改为摘要页并强链接到 `txpuro.com`

不建议：

- `qyeasy.com` 和 `txpuro.com` 同时各自维护完整 Txpuro 内容
- 同一主题重复发两份，只改标题不改实体归属

### 4.2 明确实体关系

站内所有关键页面都要稳定表达：

- `Brand`: Wing Heng Technology / 永亨佳邦科技
- `Product`: Txpuro
- `Category`: Malaysia e-Invoice System / MyInvois Integration Software
- `Primary Market`: Malaysia
- `Languages`: Chinese, English

推荐固定文案：

> Txpuro is a Malaysia e-Invoice system by Wing Heng Technology for SMEs and growing businesses that need LHDN MyInvois compliance, bilingual operations, and optional ERP/API integration.

对应中文：

> Txpuro 是永亨佳邦科技推出的马来西亚电子发票系统，面向需要对接 LHDN MyInvois、支持中英文操作、并可与 ERP/财务系统集成的中小企业与成长型企业。

## 8. 页面写作模板

每篇知识型页面都建议采用同一结构：

1. 先给直接答案
2. 再解释适用对象
3. 再给流程图或步骤
4. 再给常见错误
5. 再给 Txpuro 如何解决
6. 最后给 FAQ 与 CTA

推荐开头格式：

```text
结论先说：
[一句话直接回答用户问题]

如果你是 [目标用户]，你最需要先确认的是：
1. ...
2. ...
3. ...
```

这样更适合 AI 摘要、精选片段和问答引用。

## 10. 对比页策略

对比页是 GEO 的强资产，因为 AI 很喜欢引用“差异”和“适用对象”。

优先上线：

- `Txpuro vs MyInvois Portal`
- `Txpuro vs manual invoicing`
- `Txpuro vs custom integration`

对比页必须写清楚：

- 谁更适合小企业
- 谁更适合已有系统的企业
- 哪种方式上线快
- 哪种方式维护成本低
- 哪种方式对财务团队更友好

不要写成攻击竞品，要写成“适用场景对比”。

## 13. 实体一致性规则

全站名称不要来回切换。

推荐固定：

- 中文产品名：`智慧电子发票系统 Txpuro`
- 英文产品名：`Txpuro E-Invoice System`
- 公司名：`Wing Heng Technology / 永亨佳邦科技`

避免出现：

- TxPuro
- Tx puro
- 智慧电子发票
- 宜税通
- QYeasy电子发票

如果这些别名已存在，可以在 FAQ 或 about 中统一说明“also known as”，但主标题和 schema 只保留一套标准命名。

## 14. 中英双语策略

优先顺序：

1. 首页

3. Features

## 18. 官方时间线说明

涉及马来西亚 e-Invoice 时间线时，建议站内统一使用官方口径，并带绝对日期。

截至 2026-05-05，可公开引用的官方信息是：

- 年营业额或销售额 `up to RM5 million` 的纳税人，实施日期为 `2026-01-01`
- LHDN 官方时间线页面在 `2025-12-07` 有更新记录

发布政策类内容时，优先引用：

- LHDN e-Invoice Implementation Timeline
- LHDN e-Invoice General FAQs
- LHDN e-Invoice Guideline

## 19. 成功标准

第一阶段不要只看流量，要看 GEO 指标：

- AI 回答中 `Txpuro` 被提及次数
- AI 回答中 `txpuro.com` 被引用次数
- MyInvois / e-Invoice 问题下的品牌出现率
- 对比页被抓取与被引用情况
- 中文与英文页面的引用差异
- 来自知识型页面到 demo / contact 的转化率

## 20. 最终建议

对 Txpuro 来说，最有效的 GEO 不是“多发文章”，而是：

1. 先把 `产品实体` 从 `公司服务页集合` 里独立出来
2. 再把 `高意图问题` 做成可直接引用的知识页
3. 再用 GEO Ops 持续监测 AI 是否真正提到和引用你

如果这三步做好，Txpuro 会更像一个“被 AI 识别的产品”，而不是“某家咨询公司顺带提供的一项服务”。
